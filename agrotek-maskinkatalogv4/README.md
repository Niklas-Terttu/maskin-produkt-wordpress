# Agrotek Maskinkatalog Pro

WordPress-plugin version 3.1.0 med manuel sortering og GitHub-opdateringskontrol.

Installeres i `wp-content/plugins/agrotek-maskinkatalogv4/`.

Opdateringer distribueres via GitHub Releases med ZIP-asset `agrotek-maskinkatalogv4.zip`, hvis rodmappe skal være `agrotek-maskinkatalogv4/`.
